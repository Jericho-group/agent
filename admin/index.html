{ Дирижёр · v1.0 }

Дирижёр — это не просто бот. Это диспетчер, который маршрутизирует запросы между специализированными агентами, каждый из которых обучен своей задаче.

// 01
Масштаб без операторов
Сотни диалогов параллельно, без расширения штата
// 02
Под вашу базу знаний
RAG над pgvector — отвечает по вашим документам
// 03
CRM-интеграция
Запись лидов, BANT-квалификация, эскалация
[ ЭФФЕКТИВНОСТЬ ] // МАСШТАБИРОВАНИЕ БЕЗ НАЙМА НОВЫХ ОПЕРАТОРОВ
01
Сообщение
Клиент пишет через виджет / Telegram / API-эндпоинт POST /chat
02
Intent Router
Keyword-match → при низкой уверенности LLM (gpt-4o-mini). 8 интентов, включая escalation_request
03
Агент Дирижёр
Sales / Advisor / Support или быстрый Direct-LLM. Агент дёргает RAG (pgvector) и CRM-tool.
04
Пост-обработка
В фоне — извлечение BANT, установка флага эскалации, счётчики интентов в session_meta.

Инфраструктура

API + Дирижёр
FastAPI + Дирижёр
контейнер chatbot_app, uvicorn на :8000
Хранилище
PostgreSQL 16 + pgvector
23 таблицы: messages, session_meta, bookings, scheduled_jobs и др.
HTTPS / reverse-proxy
Caddy 2
авто Let's Encrypt
LLM
gpt-4o-mini / gpt-4o
через api.aitunnel.ru (OpenAI-совместимый endpoint)
Embeddings
text-embedding-3-small
1536 dim, HNSW-индекс на pgvector
Proactive / Telegram
Telethon
MTProto-аккаунты для рассылок и реактивации

Основные API-эндпоинты

GET /health — общий статус, число сессий, модели
POST /chat — {message, session_id?} → ответ агента
GET /history/{session_id} — история сессии
GET /admin/api/stats — BANT-температура, эскалации, интенты
GET /admin/api/skills — каталог навыков для вкладки Навыки
GET /admin/api/session/{id}/meta — BANT, эскалация, NPS конкретной сессии
POST /admin/api/session/{id}/escalate — вручную поднять флаг
POST /admin/ingest — переиндексировать БЗ (с X-Admin-Token)
Для admin-эндпоинтов: заголовок X-Admin-Token: <ADMIN_TOKEN>
